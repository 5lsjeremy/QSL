# Security

Report suspected QSL Runtime security issues privately through the official TethraSolutions, LLC security/support channel supplied with the product.

Do not publish credentials, private data, or exploit details in public reports.

Include:

- affected QSL version
- affected host/runtime
- reproduction steps
- impact description
- relevant diagnostics

QSL evaluates host-provided source against host-registered behavior. Hosts are responsible for deciding which functions, capabilities, descriptors, objects, and data are exposed to untrusted or semi-trusted source.

Treat runtime registrations as an application security boundary.
