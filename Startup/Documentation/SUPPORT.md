# Support

QSL Runtime support is provided through the official TethraSolutions, LLC support channel supplied with the product distribution.

## Include

- QSL version
- host/runtime version
- target platform
- minimal QSL source reproducing the issue
- parser diagnostics
- runtime provenance diagnostics
- minimal host code where necessary

## Do Not Include

- passwords
- API keys
- access tokens
- private customer data
- proprietary project source unrelated to the reproduction
- personal or family information

Support covers QSL integration and documented product behavior. Custom host architecture, domain design, and application-specific implementation may require separate services.
